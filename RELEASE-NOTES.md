# PlayFusion Runtime Collection 1.0

Individual Kazeta-compatible `.kzr` runtime downloads for vanilla Kazeta,
Kazeta+, and PlayFusion.

## Included

- 37 runtime images totaling approximately 5.0 GiB
- Classic consoles, handhelds, arcade, DOS, ScummVM, Linux, Windows, PS2,
  Wii/GameCube, Wii U, 3DS, Vita, and original Xbox support
- SHA-256 manifest for every download
- No games, ROMs, BIOS files, firmware dumps, keys, saves, or profiles

Download only the `.kzr` files you need. See the repository README and runtime
catalog for installation instructions, compatibility notes, and firmware
requirements.

The Nintendo 64 package is the PlayFusion-tuned 720p-internal/1080p-output
variant. Other source/origin distinctions are documented in the catalog.
